# Docs

This folder contains project documentation that isn't part of the GitHub-standard top-level docs.

## Structure

- `design/` — project axioms, design notes, and internal plans.
- `references/` — upstream/reference material or large doc dumps used for development.
- `checklists/` — operational checklists (e.g. “before pushing”).

If you link to docs from code/docstrings, prefer paths under `docs/` so the repo root stays uncluttered.
